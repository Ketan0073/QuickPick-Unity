# QuickPick - Unity Game 

"QuickPick" is a fast-paced 2D Unity game where players spot the different tile among 9 using 4 secret visual rules. Time-based scoring (3/2/1 pts) with 3 lives creates addictive reaction gameplay."**

## Gameplay  
Each round follows ONE different rule.
Pick the only Odd tile among 9 fading ones!!! 

## Features  
- 4 gameplay rules (Color/Size/Pattern/Dots)
- Progressive difficulty + scoring system
- AudioManager + SFX
- Responsive WebGL
- Local high scores

## Controls  
Mouse/Touch: Click odd tile among 9


## Requirements  
- Unity 2022.3+ (WebGL supported)
- Web browser (Chrome/Firefox recommended)
- Mouse/Touch input

## Quick Start  ← REQUIRED: 3-step setup
1. Download ZIP or clone repo
2. Open folder in Unity Hub
3. File → Build Settings → WebGL → Build & Run
